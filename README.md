# Osman Demir — Kişisel Portföy

Bu proje, Osman Demir'in web geliştirme alanındaki öğrenme sürecini, becerilerini ve çalışmalarını sergilemek için hazırladığı kişisel portföy sitesidir.

## Gereksinimler
- Node.js
- npm

## Yerel ortamda çalıştırma
```bash
npm.cmd install
npm.cmd run dev
```
Ardından http://localhost:3000 adresini açın.

## Teknolojiler
- Next.js
- React
- TypeScript
- Tailwind CSS
